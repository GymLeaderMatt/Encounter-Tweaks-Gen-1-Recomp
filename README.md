# What is this?

- This mod aims to emulate the manips found in the any% speedrun. \
- This was made with solo running in mind. \
- Wild encounters and HM users should never be the deciding factor in a race to see who can beat the game the fastest.

# Specifics

- Turns off wild encounters until you can buy repels.\
- This includes Route 1, 3, 6, and 22, Viridian Forest, and Mt. Moon B1F/B2F.\
- Mt. Moon 1F will force the encounter table to be all Paras. When you catch Paras, the encounter rate will then turn to 0.\
- Route 16 similarly will populate with Doduo and turn off when it is caught.\
- The Pokeball is also changed to be a 100% guaranteed catch.

# Toggles

- These are all toggles if you want guaranteed catches, early encounters, or the guaranteed HM users in any combination.

# Conclusion

- This was made with my personal solo run ruleset in mind. It isn't for everyone but I'm putting it out there just in case.
